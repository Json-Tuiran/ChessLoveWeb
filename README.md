# 💖 ChessLove Web

Aplicación web de ajedrez romántico y educativo diseñada especialmente para parejas.

## 📁 Estructura del Proyecto
- `CHESSLOVE_WEB_SPECIFICATION.md`: Especificación técnica exhaustiva de cada componente, motor, sonido, red y pantallas.
- `public/assets/pieces/`: Las 12 piezas de ajedrez en 3D con fondo transparente optimizadas en formato `.webp`.
- `public/assets/logo.png`: Logo oficial de ChessLove.
- `.agents/`: Reglas y habilidades de Antigravity para continuar el desarrollo directamente con la IA en este directorio.

## 🚀 Puesta en Marcha
Para iniciar el proyecto con Vite:
```bash
npm create vite@latest . -- --template react-ts
npm install
npm install mqtt lucide-react canvas-confetti
npm run dev
```
