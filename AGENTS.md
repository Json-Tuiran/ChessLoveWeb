# ChessLove Web — Workspace Context

Bienvenido al proyecto **ChessLove Web**.

## 📌 Guía de Inicio Rápido
1. Este proyecto es la versión Web (SPA / PWA) de la aplicación de ajedrez romántico **ChessLove**.
2. Toda la arquitectura técnica, lógica de ajedrez, protocolos de comunicación en tiempo real, esquemas de sonido Web Audio API y módulos de lecciones están detallados en:
   - [`CHESSLOVE_WEB_SPECIFICATION.md`](./CHESSLOVE_WEB_SPECIFICATION.md)
3. La carpeta `public/assets/` contiene:
   - Las 12 piezas 3D con fondo transparente en `public/assets/pieces/`
   - El logo oficial de la app en `public/assets/logo.png`
4. Hay una habilidad de Antigravity preinstalada en `.agents/skills/chesslove-web-master/SKILL.md` para asistir en el desarrollo integral de la app.
